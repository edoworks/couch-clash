# Couch Clash retirement

The owner retired Couch Clash on 2026-10-25. The web game, delivery scorecard,
and any remaining native test distribution are being withdrawn. This repository
and its dated release plans are historical evidence, not a current offer or an
instruction to resume development. Existing browser and device data should not
be erased remotely. Foculoom's recovery archives preserve the source and review
history before public hosting and this repository are removed.
